
# PBUI

PBUI is an experimental interface for Python.

It is based on the Listener on the Symbolics Lisp Machine.
Except with Python instead of LISP.
And a terminal interface instead of the graphical environment of Genera.

The Genera Listener was a sort of combination of a terminal and a REPL.
A terminal because you could run commands in it.
And a REPL because you could enter arbitrary LISP expressions.

If you evaluated an expression or ran a command, the resulting object was rendered as a "presentation" that you could interact with. I.e. it wasn't just plain text output like you see in a Linux terminal.

This style of interface was known as a "presentation based user interface". (That's what PBUI stands for.)
